# gis-review：上線前全面檢查

## 必守規則
1. **全程唯讀**：不改使用者任何檔案；修正要使用者同意後另做。
2. 只有找到證據（檔案:行號）才列為問題；每項附卡片編號。
3. 缺值、過期、錯誤被畫成 0 或正常值，一律列必修（05-04、09-07）。
4. 看到疑似金鑰只寫檔案與行號，值用 <REDACTED>。
5. 主對話只讀相關主題的 `_index.md`，不逐張讀卡；讀卡交給 `gis-map-kit:gis-auditor` 子代理。

知識庫在本 plugin 根目錄的 `knowledge/`（本檔往上兩層）；優先用 Read 讀已知路徑、用 Grep 搜關鍵字，Glob 若被權限擋下就改用這兩個。

## 步驟 1：認識專案（自己做，幾個工具呼叫內完成）

- 讀 package.json（或同等檔案）判斷 stack：mapbox-gl／maplibre-gl／leaflet／deck.gl／three／openlayers，以及 React／Vue／純 JS。
- 找地圖初始化、圖層定義、資料載入的位置，順便記下：底圖來源、資料格式與檔案大小、有沒有時間軸或動畫、有沒有部署設定或後端。這些決定步驟 2 挑哪些主題。
- 問使用者一句：這是給誰用的（研究、課堂、公開網站）、手機重不重要。公開網站才檢查 SEO 與嵌入。

## 步驟 2：只挑相關主題，派子代理掃描

依步驟 1 的偵測結果挑主題（通常 4–8 個），**只讀這些主題的 `_index.md`**，依 stacks 欄篩掉不適用的卡（不含該 stack 也不是 any 的跳過）：

| 偵測到 | 主題 |
|---|---|
| 任何地圖專案（基本盤） | 02-basemaps、05-color、06-data-formats、09-design-system |
| 呼叫 TDX、氣象署、環境部、data.gov.tw 等 API | 01-taiwan-apis |
| 時間欄位、時間軸、播放、requestAnimationFrame、動畫 | 03-dynamics、04-effects-catalog |
| 點數上千、單檔數 MB 以上、PMTiles、熱區／網格 | 07-performance、14-scale-density |
| 多個圖層開關、網址記住畫面 | 08-multi-layer |
| 部署設定（vercel／netlify／wrangler／Dockerfile／CI）、後端、資料庫、`.env` | 10-ops |
| 公開網站、要嵌入或被搜尋 | 11-extras |
| 風場、海流、航班、船舶、衛星、地震、落雷資料 | 12-domain-pitfalls |
| turf、緩衝、熱點、可達性、地理編碼 | 16-spatial-analysis |
| 第一次做的單頁專案、沒有建置工具 | 15-getting-started |

不掃 00-system-thinking 與 13-author-taste（設計風格不是問題）。

把篩好的卡依主題分成最多 3 組，用 `gis-map-kit:gis-auditor` 子代理（subagent_type 填這個全名）平行掃描。每組給它：專案路徑、stack、**這組的主題清單與卡片 id 清單**，以及 `knowledge/` 的**絕對路徑**（本 skill 的 base directory 往上兩層；子代理不知道 plugin 裝在哪）。讀卡、搜尋都由子代理做，主對話只收它回報的命中表。

## 步驟 3：報告

依嚴重度分三級，每項寫：問題、證據（檔案:行號）、建議怎麼修、對應卡片 id。

- **必修**：會讓資料錯、壞掉或外洩。例如缺值畫成 0、時區錯、金鑰進前端 bundle、開放資料含個資照樣顯示、沒有 loading／錯誤狀態、沒有 attribution、用沒帶 key 的 CARTO 圖磚（整片浮水印，02-02）。
- **建議**：使用者體驗或維護性明顯變好。例如沒標資料時間、手機互動不能用、圖例和顏色不同源、重繪過多。
- **可加分**：分享網址、嵌入、SEO、動態效果、無障礙。

另列兩類：
- **看不出來**：靜態掃描無法判斷的項目（例如手機實機手感、實際載入速度），寫出要怎麼人工驗。
- **沒有偵測到問題的主題**：一句帶過，不逐項列。

使用者另外問到設計風格（底圖、配色、字型、動態預設）時，才參考 `13-author-taste` 的 13-00 總表，講明是作者偏好、可以不同。

## 步驟 4：下一步

問使用者要先修哪幾項；使用者同意後才動手，修的時候依卡片解法做。

## 原則

- 卡片寫「僅限某架構」的偵測，不適用時不列。
- 不把 General 類卡片的建議寫成「一定要做」，放在建議或可加分。
