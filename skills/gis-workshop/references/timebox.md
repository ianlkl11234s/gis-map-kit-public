# 105 分鐘檢查點與降階

時間是建議，用來幫學生取捨；初學者落後時先縮功能與範圍，不縮資料誠信。45 分鐘時應有靜態版（里程碑，可以交）；動態是完整目標，來不及就先把靜態版收尾交付。

| 時間 | 學生要做的事 | 這站的證據 | 卡住時怎麼縮 |
|---|---|---|---|
| 00–10 | 選問題、區域與動態路徑（入門靜態／Change／Flow／Propagation／Scenario，沒題目看 question-bank.md）；確認本機能跑 server | 一句研究問題＋路徑＋要比較的兩個以上狀態 | 縮成一區、一層、一個指標 |
| 10–25 | 拿小樣本；確認來源、授權、座標系、時間欄位、資料粒度 | 來源摘要＋樣本能解析＋判斷能不能撐所選動態 | 自己抓不到就用講師提供的下載連結或本機資料；也沒有就改選有公開歷史或兩期資料的題目，或先做靜態版（TDX 等要註冊的 API，帳號要課前辦好，見 dynamic-paths.md） |
| 25–45 | 底圖＋第一份真實資料（**里程碑**） | 本機頁面開得起來、定位到資料；筆數與畫面對得上 | 靜態 GeoJSON、少量資料、免 key 底圖（15-05） |
| 45–60 | 圖例、配色、popup、來源與資料時間 | 圖例與地圖同源；缺值不是 0；來源時間看得到 | 一個圖層、一個單位、一套色階 |
| 60–90 | **動態控制（完整目標）**：時間、片段或情境切換 | 至少兩個狀態可切換，地圖內容真的變 | 不做動畫、縮小範圍，保留兩期或兩情境切換；仍來不及就跳到驗收，交靜態版 |
| 90–105 | 瀏覽器 QA、截圖、README、QA.md；有空才部署 | 真實瀏覽器切換成功、沒有重要 console 錯誤 | 不部署，先確保本機能重現 |

## 對應講師六階段 Demo

講師的六個階段是同一題材、同一份資料逐步長出來的完整狀態。學生不用照同樣節奏從零做；講師提供 Demo 程式時，可以拿來改成自己的資料與問題。

## 最小技術預設（學生沒有偏好時）

- 單一 `index.html`＋`data/` 資料夾，用 `python3 -m http.server` 開（雙擊開 HTML 讀不到資料，15-03）。
- MapLibre GL JS＋底圖照 `knowledge/DEFAULTS.md`（OpenFreeMap dark，免 key，骨架見 15-05），attribution 保持開啟（02-07）。沒帶 key 的 CARTO 圖磚會出浮水印，不要用（02-02）。
- 資料用 GeoJSON；切換期別或情境用 `setFilter`、`setPaintProperty` 或 feature-state，不必每次重載整份資料（04-08）。
- 狀態切換用按鈕或下拉選單即可；slider 也行，但要讓地圖內容跟著變。
