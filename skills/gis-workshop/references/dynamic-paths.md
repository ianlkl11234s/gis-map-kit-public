# 四條動態路徑：需要什麼資料、最低互動、不能做什麼

動態是完整目標，不是交件門檻；靜態版就可以交。動態不等於動畫，做到的標準是「操作後地圖內容有意義地改變」。先確認資料撐得起，再寫程式。

- **入門靜態**：先交靜態版；有餘力再加一項切換（換指標、換年份、換篩選條件），切換的兩個狀態都要是真實資料。
- **第一手／參與式**：自己收的資料用「待查核／已查核」或觀測日期切換；個資與授權注意事項見 `question-bank.md` 第 5 類。

| 路徑 | 資料需要 | 課堂最低互動 | 禁止 | 先讀 |
|---|---|---|---|---|
| Change（變化） | 同一空間單位至少兩期、同口徑（同分母、同定義） | 切換兩期，或切換「差異」圖；色階門檻跨期固定 | 自造中間期、混不同分母、缺測補 0 | 05-09、06-07、04-08 |
| Flow（流動） | 帶時間戳的實際位置，或有真實時間片段的事件／流量 | 切時間片段、依時間累積軌跡、更新點位 | OD 當 GPS 位置、跨斷訊連線、外推位置 | 12-04、04-02、04-16、03-04 |
| Propagation（傳遞） | 實測抵達時間，或有出處／明示假設的傳遞規則 | 切換階段，看影響範圍改變 | 沒有機制卻說是真實傳播過程 | 04-16、06-08 |
| Scenario（情境） | 至少兩組預先算好的結果＋參數或模型描述 | 切換情境，地圖結果不同 | 把模擬畫成實測、憑空產生數字 | 06-08 |

## 資料驗證：寫進 README 的來源摘要

每份資料至少記：機關或作者、網址或資料集編號、授權、資料時間（觀測時間，不是下載時間；兩者都記更好）、筆數、座標系、用到的欄位與單位、已知缺漏。查不到的欄位寫「查不到」，不要猜（01-12、01-13）。

## 常見情境怎麼處理

- **只有即時 API（只給現在）**：不能做歷史回放（01-10）。給學生兩個選擇：
  1. 自己抓兩個時間點的快照（隔 5–10 分鐘），課堂內就做「現在」與「下一次快照」兩期 Change，或用兩次快照的點位做 Flow，並寫明時間範圍很短；
  2. 改用有歷史的來源，或用講師提供的下載連結或本機資料。
  兩個都做不到就先交靜態版（「現在」的分布圖）。
- **自己抓 TDX 公車即時位置**（2026-11-02 實測：不帶金鑰呼叫 `tdx.transportdata.tw` 的 API 回 401「Valid API Key Required」，必須註冊）：
  1. 在 TDX 官網（https://tdx.transportdata.tw）註冊會員，完成 Email 驗證；帳號要經管理員審核，官方沒寫要多久，**課前就要辦**，課堂當下才申請可能來不及。
  2. 登入後在會員中心建立 API 金鑰，拿到 Client Id 與 Client Secret。
  3. 用本機 `python3` 腳本以 Client Id／Secret 換 access token，再抓公車即時位置（例如 `/api/basic/v2/Bus/RealTimeByFrequency/City/Taipei`），存成 GeoJSON 並記下抓取時間；隔 5–10 分鐘再抓一次。官方範例程式：https://github.com/tdxmotc/SampleCode ，接法與限流見 01-01。
  4. Client Secret 只放在本機腳本或環境變數，不寫進 `index.html`、不進公開 repo（10-04、01-08）；網頁只讀存好的 GeoJSON。
  5. 授權照 TDX 官網條款，README 與畫面要顯名標示來源。
  沒有帳號或審核沒過時，改用講師提供的下載連結或本機資料，或先交靜態版。
- **軌跡有斷訊**：依時間或距離門檻切段，斷開的地方不畫線；可以標「此段無資料」（12-04）。
- **兩期口徑不同**（行政區改制、分母改變、定義變更）：先換成可比的指標或單位；做不到就換題或改路徑，不能直接相減。
- **資料只有一期**：不是 Change。可以改問「哪裡高、哪裡低」再找第二期，或改走 Scenario／Propagation（需有出處或明示假設）；都不行時，用講師提供的下載連結或本機資料；也沒有就先交一期的靜態版。
- **找不到任何真實資料**：可以先用 `synthetic-demo` 練習寫切換程式，但還沒達到里程碑（里程碑要真實資料）；在 QA.md 標未達成，並建議換題（`question-bank.md`）。

## 互動不算數的例子

- slider 動了、標題年份變了，但地圖顏色或點位沒變。
- 兩個按鈕載入的是同一份資料。
- 播放動畫是在兩期之間自己插出中間值。
