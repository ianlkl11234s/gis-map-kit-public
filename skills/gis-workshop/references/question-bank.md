# 題庫：五類題目與可用的台灣開放資料

學生沒有題目時，從這裡挑一類再縮成一句研究問題。題目例子只是方向，**拿到樣本、確認來源授權時間之前，都不承諾一定做得出來**。卡片編號指 `knowledge/` 裡的卡。

每張題目卡都寫：研究問題、資料來源、幾何類型、動態需要的欄位、限制。

## 1. 入門靜態

先讓一份真實資料上地圖，是第一個里程碑。

- 臺北市各行政區人口密度或高齡人口比例。
- 醫療院所、公共設施（圖書館、運動中心）的分布；只是分布圖，沒做路網分析就不要叫「可達性」（16-04）。
- 某一天的空氣品質測站數值。

建議來源：01-06（行政界與人口）、01-05（data.gov.tw 與授權）、01-03（環境部）、01-00（平台總覽）。
動態做法：先交靜態，有餘力再加一項切換（換指標、換年份、換篩選條件），讓地圖內容改變。

## 2. Change（變化）

同一空間單位、同口徑的兩期比較。

- 臺北市各行政區人口 2015 年 vs 2025 年（同一套行政區界、同一個人口定義）。
- 兩個年度的同一項統計（例如老年人口比例）。
- 停車場或公共設施在兩個時間點的數量變化。

建議來源：01-06、06-14（統計圖層可比性）、06-07（分母）。
動態做法：切換兩期，或切「差異」圖；色階門檻跨期固定（05-09）。行政區改制、分母不同就不能直接相減。

## 3. Flow（流動）

有時間戳的實際位置或事件，看它怎麼移動。

- 早上某條公車路線的車輛位置隨時間變化。
- 一段時間內的航班或船舶軌跡（要有可轉交的授權）。

建議來源：01-01（TDX）、01-10（即時 API 沒有歷史）、12-04（斷訊切段）。
動態做法：時間滑桿或時間片段切換點位；斷訊切段不連線，不外推、不補中間位置。即時 API 只給現在，要回放得先有快照。目前講師有一份「雙北公車 2026-10-28 07:00–09:00」的快照，若講師課堂有發放就可以用。

## 4. Propagation／Scenario（傳遞／情境）

- Propagation：一次地震的震度分布，依測站實測時間或明示的波速假設分階段顯示。
- Scenario：兩種預先算好的情境比較，例如不同降雨量的淹水潛勢、封橋前後的可達範圍。

建議來源：01-02（氣象署地震報告）、01-04（水利署）、06-08（推估與模擬要標示）、04-16（不假造動態）。
動態做法：切換階段或情境，地圖結果不同；寫明參數、模型或假設。沒有機制就不能說是真實傳播過程，模擬不能畫成實測。

## 5. 第一手／參與式（進階）

自己收集的資料，例如校園無障礙障礙點、街道樹況巡查、用表單或手機照片標點。

- 先做小規模示範觀測，取得受訪者或拍攝對象同意；105 分鐘內不要做完整的公開通報平台。
- 個資：不收姓名、電話；照片避開人臉與車牌，或先模糊；精確住家位置不公開（01-07）。
- 授權：自己拍的照片與自己收的資料，寫明要用什麼授權公開；借用別人的照片要確認授權（10-22）。
- 件數是「回報到的件數」，不是實際發生數（16-06）。
- 動態做法：設計「待查核／已查核」兩種狀態切換，或切換觀測日期。

## 資料來源兩種分法的對照

課程簡報用「來源 × 性質」分：來源有政府、企業、國際組織、學術、開放資料衍生、自建收集器、公民回報；性質有靜態、動態（持續收集）、自己再加工。卡片 01-16 用六類，對照如下：

| 簡報 | 01-16 |
|---|---|
| 政府、企業、國際組織、學術的靜態資料 | 1a 開放資料（OSM 另歸 1b） |
| 動態（持續收集）、自建收集器 | 1c 要打 API 持續收集 |
| 開放資料衍生、自己再加工 | 2a 行政區統計、2b 影像辨識、2c 都市熱島 |
| 公民回報、田野調查 | 01-16 沒有對應類別，照本檔第 5 類處理 |
